# Hangman Game
A simple word guessing game built using python only.This game randomly selects a word and user have to guess that word by writing a letter at a time

## Features
- Random word selesction
- Limited attempts
- "_" in place of blank letters
- multiply letters at a time
- Win or lose condition
- Command line interface

## Technologies used
- Python
- Random module
- list
- loops
- If else
- String


## How to play 
Run the program.
Guess one letter at a time.
Correct guesses reveal the letter's position.
Wrong guesses reduce the remaining attempts.
Guess the complete word before attempts reach zero.
Example  
Word: _ _ _ _ _ _  
Enter letter: p  
p _ _ _ _ _  
Enter letter: y  
p y _ _ _ _
